## envbuild

Build .env from a schema

### Synopsis

Envbuild allows you to build your .env files from a schema.
Envbuild generates .env file using the env vars or by a key value store.

```
envbuild [flags]
```

### Examples

```

- envbuild <path>

This looks .envbuild.toml files in <path> and builds .env in it.

- envbuild --env-file <file-path>

This loads <file-path> and builds .env in the base path.
```

### Options

```
  -e, --env-file string   env file path (default ".envbuild.toml")
  -h, --help              help for envbuild
```
